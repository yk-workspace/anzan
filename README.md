# 暗算ドリル

紙の100マス計算の代わりになる、暗算の連続問題アプリです。
スタートを押すと問題が自動で進み、丸付け・記録・やり直しまでアプリが行います。

`index.html` ひとつで動作し、オフラインでも使えるPWAです（外部CDN・外部フォントは使っていません）。

## 特長

### 自動ペースで「ダラダラ」を防ぐ
- スタート → カウントダウン（3・2・1）→ 問題が次々に出ます。「次へ」を押す必要はありません
- 1問ごとの制限時間のバー表示。時間切れは不正解として次へ進みます
- ペースは5種類：**自動（ゆっくり／ふつう／はやめ）**、固定秒数、なし（時間制限なし）
  - 自動の制限時間は、問題の種類（レベル・演算・くり上がり／くり下がりの有無・小数の有無）ごとの直近10問の平均から決めます
  - ゆっくり：平均×2.5＋2秒（上限は基準秒の3倍）／ふつう：平均×2＋1秒／はやめ：平均×1.5＋1秒（上限は基準秒の2倍）
  - 時間切れは「制限時間の1.5倍」として記録します。間違えた問題・再出題・やり直しは記録しません
  - 履歴が3問たまるまでは、基準秒の2倍です。開始前の画面に、いまの制限時間のめやすを表示します
- 声で進行：問題の読み上げ、「せいかい」「あと3もん」などの声かけ（個別にオフ可）
  - 声の種類は「自動（おすすめ）」のとき、日本語の声の中から自然そうなもの（Natural → Premium/Enhanced/拡張 → Google → 標準の順）を自動で選びます。設定画面で好きな声に変えることもできます
- 桁数がそろったら自動で確定（初期値はオフ。打ち間違いの防止のため）
- 👁ボタンで、問題を画面に表示しない（読み上げだけで解く）練習ができます。読み上げがオフのときは常に表示します。問題のところをタップすると、もう一度読み上げます
- 3問連続で時間切れなら「ちょっと休けいする？」で一時停止
- ⏸ボタン、または別のアプリに切り替える・画面が消えると自動で一時停止します（制限時間も止まり、再開すると続きから）

### 問題
- たし算・ひき算・かけ算・わり算を個別にオン／オフ（混ぜて出題も可）
- たし算・ひき算：11段階（1桁±1桁のくり上がりなし → 2桁±2桁 → 3桁 → 2桁を3つ・4つ…）
  - 「なし」のレベルは、くり上がり・くり下がりのない問題だけを出します
  - 「あり」のレベルは、ある問題とない問題を混ぜて出します（ある問題が半分以上になるよう調整）
  - レベル2（1桁＋1桁のくり上がり）はたし算だけのレベルです。ひき算だけでは選べず、レベルアップの提案でも飛ばします
  - ひき算は、途中も答えもマイナスになりません（3つ以上の数でも、ひき算だけの設定なら、たし算は混ざりません）
- かけ算・わり算：4段階（九九 → 2桁×2桁 → 3桁×2桁、わり算は割り切れる問題）
- **小数**（小数第1位）、**わり算のあまり**（商とあまりを入力）を選択可能

### 復習・記録
- 間違い・時間切れの問題は、同じセット内で3問後にもう一度出ます（**再出題**）
  - 再出題は、設定した問題数とは別に出ます。最後の問題で間違えても、セットの最後に必ず出ます
  - 再出題は時間制限なし。秒数は自動ペース・セットの平均・自己ベストに入れません
  - 再出題は1問につき1回まで。再出題で正解すれば、元の間違いは「済」になります
- 再出題でも間違えた問題は、セット終了後／きろくから**まちがいをやり直し**（制限時間なし、正解で「済」に）
  - やり直しの秒数は、自動ペースの計算には使いません
- 3セット連続で正答率90%以上＋時間切れなしなら、レベルアップを提案
- 自己ベスト（全問正解のときの平均秒/問）、1日の目標（達成すると紙吹雪とメッセージ）、連続練習日数、直近7日グラフ、にがてな型
- ユーザー切り替え（きょうだいで共用）、バックアップの保存・読み込み

## 使い方

`index.html` をブラウザで開くだけで動きます。PWA（ホーム画面追加・オフライン）にはHTTPSが必要なので、GitHub Pagesなどで公開してください。

### GitHub Pages で公開
1. このフォルダの中身（6ファイル）をリポジトリの直下に置いてpush
2. リポジトリの **Settings → Pages**
3. **Source** を `Deploy from a branch`、Branch を `main` / `(root)` にして保存
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

### 更新したとき
`sw.js` の `CACHE` の値（現在は `anzan-drill-v8`）を `anzan-drill-v9` のように変えてpushすると、利用者側のキャッシュが入れ替わります。

## データについて

設定と記録は、ブラウザの `localStorage`（キー `anzan2`）に保存されます。サーバーには何も送信しません。
ブラウザのデータ消去や機種変更に備えて、設定画面の「バックアップ保存」を使ってください。

## 動作環境

音声はWeb Speech API（日本語音声）を使うため、声の種類や品質は端末によって異なります。iPhone/iPadでは、最初に画面をタップしたときに音声と効果音を使える状態にしています（以降は自動で鳴ります）。
